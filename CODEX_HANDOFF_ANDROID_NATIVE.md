## Non-negotiable product requirements
- No WebView for the Android application UI.
- Kotlin + Jetpack Compose + Material 3.
- Real native Android interaction/layout similar in quality to modern mobile apps such as ChatGPT; do not emulate a desktop HTML table on mobile.
- Offline operation for all normal workflows.
- Room is the UI-facing working database.
- WorkManager performs deferred/background sync.
- Supabase remains the authoritative remote backend and Auth provider.
- No Supabase service-role secret in the APK.
- Admin may use both Admin and Teacher workspaces; Teacher may use Teacher only.
- Academic year: `2026/2027`.
- Classes: `MPI1`, `MPI2`, `MPI3`, `MPI4`, `MPI5`, `PC1`.
- Each class supports 3 or 4 TP groups.
- Attendance states: present, absent, late, justified.
- Grades are optional and restricted to 0–20.
- Native PDF report generation must work offline.
- PDF includes institution/year, teacher, class/group, module, date/time, student list, attendance, optional grade, observations, and attendance statistics.
- Adaptive launcher icon: simplified modern mark inspired by FST; navy/gold identity. Official FST/UTM logos may appear inside the app when assets are available.
- Preserve the existing Windows/browser HTML application; Android rewrite must not break it.

`Set android.useAndroidX=true in the gradle.properties file and retry.`

This has already been corrected by adding root `gradle.properties` with:
```properties
android.useAndroidX=true
android.enableJetifier=true
org.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8
```
