# Latest HTML source

This directory stores the user-provided latest HTML source as gzip/base64 chunks because the source is larger than a convenient single text update. The build workflow reconstructs `app/src/main/assets/index.html` from these chunks before Android/Windows packaging.

Expected SHA-256 after reconstruction: `d0cb9e7c26e52854a176841ac0e2c62c9105a475aa6e827571c061d97a0c152f`.
