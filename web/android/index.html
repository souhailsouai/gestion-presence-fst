Présence FST

Application Android de gestion de présence des TP — Faculté des Sciences de Tunis.

Télécharger l'application (version 2.27.0)

Version 2.27.0 (Android 16). Si votre application est antérieure à la 2.13.0 : une seule fois, désinstallez d'abord l'ancienne application « Présence FST », puis installez celle-ci. Vos présences et notes restent sur le serveur.

Ouvrez le fichier sur le téléphone et autorisez « Installer des applications inconnues ». Les versions suivantes sont proposées directement dans l'application.
